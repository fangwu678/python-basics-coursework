# Python Basics Coursework

This repository contains basic Python exercises from my bachelor's-level coursework and later review practice.

The purpose of this repository is to show my early experience with Python. It is not an advanced programming project.

## What I practised

- Functions and return values
- Lists
- `for` loops
- `if / elif / else`
- `while` loops
- The `random` module
- A simple card game using several basic Python concepts

## About the files

`01_functions.ipynb`, `02_lists_and_loops.ipynb`, `05_random_module.ipynb`,
and `06_card_game_ai_assisted.ipynb` are based on exercises that I still had
from my original coursework.

I also studied basic `if` statements and `while` loops during the course,
but those original files were no longer available. Therefore,
`03_if_statements.ipynb` and `04_while_loops.ipynb` are simple recreated
practice exercises based on the same topics.
